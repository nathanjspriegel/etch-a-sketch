# Etch-a-Sketch
A browser-based sketchpad built with HTML, CSS, and JavaScript as part of [The Odin Project](https://www.theodinproject.com/lessons/foundations-etch-a-sketch) foundations course.
## Live Demo
[View it live](https://nathanjspriegel.github.io/etch-a-sketch/)
## What I practiced
- Creating and appending DOM elements dynamically with JavaScript
- Flexbox for laying out a responsive grid without using CSS Grid
- Handling mouse events (`mouseenter`) to trigger interactive behavior
- Storing per-element state with the `dataset` API to track hover counts independently across elements
- Combining color and opacity to build a layered visual effect (progressive darkening)
- Rebuilding and re-rendering the DOM dynamically based on user input (prompt-driven grid resizing)
## Built with
- HTML5
- CSS3 (Flexbox)
- JavaScript (DOM manipulation, event listeners)
## Ideas to improve
- Making the layout responsive for different screen sizes
- Adding a "clear grid" button separate from resizing
- Supporting touch events for mobile drawing
- Smoothing out missed hover events during fast mouse movement
